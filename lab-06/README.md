# Лабораторная работа №6. Использование алиасов (Псевдонимов)

**Цель:** Научиться использовать псевдонимы для таблиц и столбцов (`AS`) для повышения читаемости и компактности SQL-запросов.

**Ход работы:**
- Написаны сложные запросы с объединением нескольких таблиц (`JOIN`).
- Применены алиасы для таблиц (например, `users AS u`, `orders AS o`), чтобы избежать дублирования длинных названий.
- Применены алиасы для вычисляемых столбцов (например, `SUM(price) AS total_amount`) для красивого вывода результатов в CLI.

**Как запустить:** Выполните запросы из файла `queries.sql`.

**Вывод:** Использование алиасов делает SQL-код значительно чище и короче, что особенно важно при написании сложных аналитических запросов.
