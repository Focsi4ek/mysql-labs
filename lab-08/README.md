# Лабораторная работа №8. Полнотекстовый поиск (FULLTEXT)

**Цель:** Изучить механизм полнотекстового поиска в MySQL для эффективного поиска по текстовым полям.

**Ход работы:**
- Создана таблица статей с полями `title` и `body`.
- Построен полнотекстовый индекс `FULLTEXT(title, body)`.
- Выполнен поиск с помощью конструкции `MATCH() AGAINST()`.
- Проверены различные режимы поиска: естественный язык (Natural Language) и логический режим (Boolean).

**Как запустить:** Выполните `schema.sql`, затем поисковые запросы из `search.sql`.

**Вывод:** Полнотекстовый поиск гораздо эффективнее обычного `LIKE '%word%'`, так как использует инвертированный индекс и позволяет искать по релевантности.
