# Лабораторная работа №7. Индексы в MySQL

**Цель:** Изучить влияние индексов на скорость выполнения запросов при поиске данных.

**Ход работы:**
1. Создана таблица с большим количеством строк (тестовый набор).
2. Выполнен запрос на поиск по столбцу `email`, план выполнения проверен с помощью команды `EXPLAIN`.
3. Создан индекс `idx_email` на этот столбец.
4. Повторно выполнен `EXPLAIN` и подтверждено, что СУБД начала использовать индекс (type: ref) вместо полного перебора таблицы (type: ALL).

**Как запустить:** Выполните `schema.sql` и проанализируйте вывод команды `EXPLAIN` из `queries.sql`.

**Вывод:** Индексы критически важны для оптимизации баз данных и сокращения времени поиска. Однако они требуют дополнительного места на диске и замедляют операции вставки.
