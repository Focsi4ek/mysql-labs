# Лабораторная работа №10. Сортировка и группировка данных

**Цель:** Освоить агрегацию данных с помощью `GROUP BY` и научиться сортировать итоговые результаты с помощью `ORDER BY`.

**Ход работы:**
- Использована таблица задач (`tasks`), созданная в предыдущих работах.
- Написан запрос с группировкой по статусу задачи (`GROUP BY status`).
- Применена агрегатная функция `COUNT(*)` для подсчета количества задач в каждом статусе.
- Результат отсортирован по убыванию количества (`ORDER BY task_count DESC`).
- Изучено применение фильтрации к сгруппированным данным с помощью оператора `HAVING`.

**Как запустить:** Выполните запросы из файла `queries.sql`.

**Вывод:** Группировка и сортировка позволяют получать сводную статистику по данным, что является основой для построения отчетов и дашбордов.
