## 🚀 Быстрый старт

Все работы выполняются в Docker, поэтому окружение поднимается одинаково для любой лабораторной.

**1. Запуск контейнера:**

```bash
docker-compose up -d
```

**2. Подключение к MySQL:**

```bash
docker exec -it mysql-labs-db mysql -uroot -p123
```

**3. Запуск скриптов:**
Внутри консоли MySQL выполните:
```sql
SOURCE lab-01/schema.sql;
```

> [!NOTE]
> Пароль `123` используется только в учебных целях. В реальных проектах так делать не стоит.
