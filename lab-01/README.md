# Лабораторная работа №1. Основные SQL-операции

**Цель:** Освоить базовые операции реляционной алгебры (выборка, проекция, объединение, разность, пересечение) и соединения таблиц (JOIN).

**Ход работы:**
1. Развернута база данных MySQL в Docker.
2. Созданы таблицы `products1` и `products2` с тестовыми данными.
3. Написаны запросы для демонстрации работы операторов `WHERE` (выборка) и `SELECT` (проекция).
4. Отработаны операции `UNION` (объединение), `EXCEPT` (разность) и `INTERSECT` (пересечение).
5. Изучены различные виды соединений: `INNER JOIN`, `LEFT JOIN` и `CROSS JOIN`.
6. Сделан дамп базы данных для возможности восстановления.

**Как запустить:** Выполните `source schema.sql`, а затем запросы из `queries.sql`.

**Вывод:** В ходе работы я научился извлекать и комбинировать данные из нескольких таблиц, что является базой для любого аналитика или разработчика баз данных.
