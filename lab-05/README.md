# Лабораторная работа №5. Нормализация данных (3NF)

**Цель:** Привести денормализованную таблицу к третьей нормальной форме (3NF) для устранения избыточности данных и аномалий обновления.

**Ход работы:**
1. Взят исходный набор данных (список сотрудников с их отделами), где наблюдалось дублирование информации.
2. Выявлены транзитивные зависимости (например, `ID отдела` зависит от `Названия отдела`, а не напрямую от сотрудника).
3. Таблица разбита на две связанные сущности: `departments` (справочник отделов) и `employees` (сотрудники), связанные внешним ключом.

**Как запустить:** Выполните `before.sql` (исходное состояние) и `after.sql` (нормализованное).

**Вывод:** Нормализация до 3NF позволила сделать структуру БД более гибкой. Теперь при переименовании отдела не нужно обновлять сотни строк в таблице сотрудников.
