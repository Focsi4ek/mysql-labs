# Лабораторная работа №4. Docker и CRUD-операции

**Цель:** Освоить базовые операции манипулирования данными (Create, Read, Update, Delete) и закрепить навыки работы с MySQL в изолированной среде Docker.

**Ход работы:**
1. Запущен контейнер MySQL с помощью Docker Compose (использован файл `docker-compose.yml`).
2. Создана таблица задач (`tasks`).
3. Выполнен полный цикл CRUD: 
   - **Create:** Добавление новой задачи через `INSERT`.
   - **Read:** Чтение списка задач через `SELECT`.
   - **Update:** Изменение статуса задачи на "Выполнено" через `UPDATE`.
   - **Delete:** Удаление выполненных задач через `DELETE`.

**Как запустить:** Поднимите Docker (`docker-compose up -d`), подключитесь к БД и выполните `crud.sql`.

**Вывод:** Я закрепил навыки работы с Docker и убедился, что CRUD-операции являются основой любого взаимодействия приложения с базой данных.
