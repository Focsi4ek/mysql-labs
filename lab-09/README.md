# Лабораторная работа №9. Нормальные формы (1NF, 2NF, 3NF)

**Цель:** Комплексно разобрать процесс проектирования реляционной базы данных на примере перехода от одной большой таблицы к структуре, соответствующей всем основным нормальным формам.

**Ход работы:**
1. **1NF:** Приведение данных к атомарному виду (устранение массивов в ячейках, например, нескольких телефонов в одной строке).
2. **2NF:** Устранение частичных зависимостей от составного первичного ключа (вынесение телефонов в отдельную таблицу).
3. **3NF:** Устранение транзитивных зависимостей (вынесение городов в отдельный справочник).

**Как запустить:** Изучите файлы `1nf.sql`, `2nf.sql`, `3nf.sql` последовательно.

**Вывод:** В итоге спроектирована схема "звезда", где каждая таблица отвечает за свой тип сущностей (контакты, телефоны, города), что исключает дублирование данных.
