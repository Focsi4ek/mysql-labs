# Лабораторная работа №3. Логирование действий (Триггеры)

**Цель:** Научиться автоматизировать запись изменений в базе данных с помощью триггеров для создания систем аудита.

**Ход работы:**
- Создана основная таблица `items` для хранения товаров.
- Создана таблица `logs` для хранения истории действий (с полями `action` и `created_at`).
- Написан триггер `after_item_insert`, который срабатывает при добавлении нового товара и автоматически записывает текстовое сообщение в лог с указанием времени события.

**Как запустить:** Выполните `source schema.sql`, сделайте `INSERT` в таблицу `items` и проверьте таблицу `logs`.

**Вывод:** Триггеры позволяют создать надежную систему логирования на уровне самой базы данных, не меняя код приложения. Это критически важно для безопасности и отладки.
