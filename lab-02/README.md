# Лабораторная работа №2. Представления (VIEW)

**Цель:** Изучить механизм представлений в MySQL и научиться использовать их для упрощения сложных запросов и ограничения доступа к данным.

**Ход работы:**
- Создана база данных и таблица пользователей с флагом активности (`is_active`).
- Сформировано представление `active_users`, которое динамически фильтрует только активных пользователей.
- Проверено, что при изменении данных в исходной таблице представление обновляется автоматически, так как оно не хранит данные, а формирует их на лету.

**Как запустить:** Выполните скрипт `schema.sql`, затем проверьте результат запросом из `queries.sql`.

**Вывод:** Представления — это удобный инструмент, который скрывает сложность структуры БД от конечного пользователя, повышает безопасность и позволяет переиспользовать сложные запросы.
